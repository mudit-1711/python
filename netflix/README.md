# Netflix Data Analysis & Visualization

This directory contains an Exploratory Data Analysis (EDA) project focusing on the Netflix movies and TV shows catalog. It covers data cleaning, processing, and visualization to extract insights about Netflix's content offerings.

## Contents

*   **[`netflix.ipynb`](file:///d:/python/netflix/netflix.ipynb)**: Jupyter notebook containing the Python code for loading, cleaning, analyzing, and plotting the Netflix catalog data.
*   **[`netflix_titles.csv`](file:///d:/python/netflix/netflix_titles.csv)**: The dataset containing content metadata (titles, cast, directors, release years, ratings, duration, etc.).
*   **Visualizations**:
    *   **[`content_rating_pie.png`](file:///d:/python/netflix/content_rating_pie.png)**: A pie chart representing the distribution of age/content ratings across Netflix.
    *   **[`movie relase year histogram.png`](file:///d:/python/netflix/movie%20relase%20year%20histogram.png)**: Distribution of movies by their original release year.
    *   **[`movie_duration_histogram.png`](file:///d:/python/netflix/movie_duration_histogram.png)**: Histogram showing the distribution of movie durations (in minutes).
    *   **[`movie_vs_tvshow.png`](file:///d:/python/netflix/movie_vs_tvshow.png)**: Comparison showing the proportion of Movies versus TV Shows in the catalog.

## Key Insights Explored

1.  **Content Type Distribution**: Visualizing the breakdown between Movies and TV Shows.
2.  **Release Year Trends**: Examining how Netflix content creation and acquisition has evolved over the decades.
3.  **Duration & Ratings Analysis**: Analyzing common runtimes for movies and understanding target audiences via content rating distributions.

## Libraries Used
*   **Pandas**: For reading, cleaning, and preprocessing the csv dataset.
*   **Matplotlib**: For rendering high-quality diagnostic plots and charts.
