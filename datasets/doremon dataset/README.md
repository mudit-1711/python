# Doraemon Franchise Dataset

This directory contains a complete fan-curated dataset detailing the Doraemon universe, covering characters, episodes, futuristic gadgets, movies, themes, and character images.

## Contents

### 1. Tabular Datasets

*   **[`character_list.csv`](file:///d:/python/datasets/doremon%20dataset/character_list.csv)**: Detailed profiles of major and minor characters:
    *   *Columns*: English Name, Japanese Name, Gender, Species, Age, Birth Date, First Appearance, and Role.
*   **[`episodes_list.csv`](file:///d:/python/datasets/doremon%20dataset/episodes_list.csv)**: Complete list of Doraemon episodes:
    *   *Columns*: Episode ID, Title (EN/JP), Air Date, Duration, Season, Plot Summary, and Featured Gadget.
*   **[`gadget_list.csv`](file:///d:/python/datasets/doremon%20dataset/gadget_list.csv)**: Catalog of 22nd-century gadgets pulled from Doraemon's 4-dimensional pocket:
    *   *Columns*: Gadget Name, Description, and First Episode Appearance.
*   **[`movie_list.csv`](file:///d:/python/datasets/doremon%20dataset/movie_list.csv)**: Box office history and metadata of theatrical films:
    *   *Columns*: Title (EN/JP), Release Year, Duration, Director, Production Studio, and Box Office Earnings.
*   **[`songs_list.csv`](file:///d:/python/datasets/doremon%20dataset/songs_list.csv)**: Compilation of opening and ending tracks, inserts, and background themes:
    *   *Columns*: Title, Title (JP), Artist, Song Type, and Lyrics Excerpts.

### 2. Image Classification Assets

The **[`images/`](file:///d:/python/datasets/doremon%20dataset/images/)** directory is split into categories to facilitate image classification, object detection, and CNN practice:

*   **[`images/Doraemon/`](file:///d:/python/datasets/doremon%20dataset/images/Doraemon/)**: Profile images and illustrations of the robotic cat, Doraemon.
*   **[`images/Nobita/`](file:///d:/python/datasets/doremon%20dataset/images/Nobita/)**: Image assets of Nobita Nobi.
*   **[`images/Shizuka/`](file:///d:/python/datasets/doremon%20dataset/images/Shizuka/)**: Image assets of Shizuka Minamoto.
*   **[`images/Suneo/`](file:///d:/python/datasets/doremon%20dataset/images/Suneo/)**: Image assets of Suneo Honekawa.
*   **[`images/Gian/`](file:///d:/python/datasets/doremon%20dataset/images/Gian/)**: Image assets of Takeshi "Gian" Goda.
*   **[`images/Test/`](file:///d:/python/datasets/doremon%20dataset/images/Test/)**: Unlabeled validation test subset.
